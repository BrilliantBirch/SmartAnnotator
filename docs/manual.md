## 1. 产品概述

BrilliantAnnotator 是一款基于深度学习模型的智能数据标注工具，采用 labelme 风格的三栏式标注编辑器布局，标注数据完全兼容 LabelMe JSON 格式。核心功能：

| 功能             | 说明                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| **人工标注编辑** | 矩形 / 点 / 多边形三种标注工具，支持对象属性（标签/描述/分组）、复制粘贴、撤销重做、多选 |
| **自动标注**     | 加载 ONNX / TensorRT 模型，对单张图片、全部图片、视频批量推理，自动生成 LabelMe 标注     |
| **格式转换**     | 导出（LabelMe JSON → YOLO TXT，含数据集划分）与导入（YOLO TXT → LabelMe JSON）双向转换   |
| **数据集统计**   | 后台扫描工作目录标注文件，汇总标签种类、实例个数与标注形状分布                           |

支持的任务模式：

| 任务模式            | 自动标注 | 格式转换 |
| ------------------- | -------- | -------- |
| 目标检测（DETECT）  | 支持     | 支持     |
| 姿态估计（POSE）    | 支持     | 支持     |
| 实例分割（SEGMENT） | 支持     | 支持     |
| 文字识别（OCR）     | 支持     | 预留接口 |

## 2. 系统要求

| 项目     | 要求                                                  |
| -------- | ----------------------------------------------------- |
| 操作系统 | Windows 10 / 11（64 位）                              |
| CPU 版   | 无特殊要求，4 GB 以上内存                             |
| GPU 版   | NVIDIA 显卡 + 已安装显卡驱动（无需安装 CUDA Toolkit） |
| 磁盘空间 | 安装约 1 GB（GPU 版），输出目录预留足够空间           |

**GPU 版说明：**

- GPU 推理基于 TensorRT 引擎，仅需安装 NVIDIA 显卡驱动，无需单独安装 CUDA Toolkit 或 cuDNN。
- GPU 模式下首次使用 ONNX 模型时，程序会弹窗确认将其转换为 TensorRT engine（约需 10~30 分钟，视模型大小而定），转换结果保存在模型同目录下，之后自动复用。
- 若系统未检测到 CUDA 环境，运行设备选择中的 GPU 选项将被自动禁用，仅支持 CPU 模式。

## 3. 安装与启动

### 3.1 安装器安装

1. 双击安装程序（如 `BrilliantAnnotator_Setup_GPU.exe`）。
2. 按向导提示选择安装目录，完成安装。
3. 从开始菜单或桌面快捷方式启动程序。

### 3.2 开发环境运行（源码）

```bash
conda create -n BrilliantAnnotator python=3.12.10
conda activate BrilliantAnnotator
pip install -r requirements.txt
python -m smart_annotator
```

## 4. 界面总览

程序主窗口为 **三栏式标注编辑器**：

| 区域           | 内容                                                                                                                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **菜单栏**     | 文件 / 编辑 / 视图 / 工具 / 统计 / 帮助 六个菜单                                                                                                                                                            |
| **图标工具栏** | 菜单栏下方的图标按钮组（悬停显示功能与快捷键）：文件操作组（打开文件夹/打开文件/保存/另存为/适应窗口/删除选中/删除图片文件）+ 标注工具组（编辑/矩形/点/多边形，互斥选中）；自定义改键后按钮悬停提示自动同步 |
| **中间画布**   | 图像显示与标注绘制/编辑区；Ctrl+滚轮以光标为锚缩放，无修饰键滚轮垂直滚动浏览（放大后可浏览图像）                                                                                                            |
| **右侧信息栏** | 单一"对象面板"停靠窗口，内含 标签列表 / 对象列表 / 文件列表 三个分区；面板宽度与分区高度均可经分隔条拖拽调节                                                                                                |
| **状态栏**     | 显示当前图片序号（如 `3/120`）、文件名与未保存标记（`（未保存）`）                                                                                                                                          |

- 右侧"对象面板"可浮动成独立小窗、自由移动、拖回停靠或关闭；面板整体宽度经分隔条拖拽自由调节（无上限），三个分区高度经面板内垂直分隔条拖拽调节；工具栏与面板布局（位置/尺寸/显隐/分区高度）自动持久化（下次启动恢复）。
- 界面配置持久化于 `%APPDATA%/BrilliantAnnotator/render_config.json`。
- 未打开图片时，编辑相关功能自动禁用。

## 5. 文件操作（文件菜单 / 图标工具栏）

| 操作           | 入口                                  | 说明                                                                                                     |
| -------------- | ------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 打开文件夹     | 文件 → 打开文件夹（Ctrl+O）           | 选择目录后自动扫描其中图片（jpg/jpeg/png/bmp），并加载第一张                                             |
| 打开文件       | 文件 → 打开文件（Ctrl+Shift+O）       | 打开单个图片或 LabelMe JSON 标注（标注会自动关联同名/同目录图片）                                        |
| 保存           | 文件 → 保存（Ctrl+S）                 | 将当前标注写入与图片同名（扩展名 `.json`）的 LabelMe 标注文件                                            |
| 另存为         | 文件 → 另存为（Ctrl+Shift+S）         | 选择目标路径保存当前标注                                                                                 |
| 自动保存       | 文件 → 自动保存（勾选，默认开启）     | 开启后每次切换图片前自动保存当前标注；无修改且无标注文件时不产生空文件；勾选状态自动记忆（下次启动恢复） |
| 删除图片及标注 | 编辑 → 删除图片及标注（Shift+Delete） | 删除当前图片与其同名标注文件（弹确认框，可勾选"不再提醒"），并自动加载下一张                             |

**未保存提醒：** 当前标注存在未保存修改时，切换图片、打开新目录/单图/标注文件、关闭程序前均会弹出提醒（**保存 / 不保存 / 取消** 三选，取消则中断切换）；开启自动保存时改为静默自动保存，不再弹框。

## 6. 人工标注

### 6.1 标注工具

图标工具栏/工具菜单提供四种互斥工具（括号内为快捷键）：

| 工具   | 快捷键     | 说明                                                                                          |
| ------ | ---------- | --------------------------------------------------------------------------------------------- |
| 编辑   | V / Ctrl+E | 编辑模式：选中、拖拽移动、端点缩放、修改属性                                                  |
| 矩形   | R          | 点击两个对角点绘制矩形框                                                                      |
| 点     | P          | 单击放置关键点；关键点渲染为白描边实心圆点，大小可在 视图 → 关键点大小 调节，半径跟随图像缩放 |
| 多边形 | G          | 逐点点击绘制多边形，闭合后完成                                                                |

**绘制辅助线：** 矩形 / 多边形绘制过程中，光标位置显示贯穿画布边缘的虚线十字延长线（便于对齐已有对象）；点工具不显示延长线（十字光标由鼠标指针提供）。绘制工具下鼠标指针为十字准星。

### 6.2 绘制流程与属性弹窗

绘制完成（矩形第二点点击 / 多边形闭合 / 点放置）后弹出 **"标注对象属性"** 窗口：

- **标签：** 输入框即时过滤下方已有标签列表；单击选择、双击选择并确认，也可直接键入新标签。
- **Group ID：** 可编辑下拉框，下拉项为当前画布已有组号（去重升序），也可键入新值；留空表示不分组。
- **描述：** 底部输入框填写备注（可选）。
- **取消或标签为空：** 该形状不生效（静默丢弃，状态栏提示"未设置标签"）。

### 6.3 编辑操作（编辑菜单 / 画布右键菜单）

| 操作           | 快捷键       | 说明                                                         |
| -------------- | ------------ | ------------------------------------------------------------ |
| 撤销           | Ctrl+Z       | 撤销上一步绘制/编辑；多边形绘制中撤回上一顶点                |
| 重做           | Ctrl+Shift+Z | 重做（多边形绘制中忽略）                                     |
| 复制           | Ctrl+C       | 复制画布选中对象到画布内部剪贴板                             |
| 粘贴           | Ctrl+V       | 粘贴剪贴板中的对象                                           |
| 删除选中标注   | Delete       | 按焦点上下文路由（见 6.4）；弹确认框，可勾选"不再提醒"       |
| 清空标注       | —            | 清空当前图片全部标注（弹确认框，可勾选"不再提醒"；不可恢复） |
| 删除图片及标注 | Shift+Delete | 删除当前图片文件与其标注文件（弹确认框，可勾选"不再提醒"）   |
| 适应窗口       | Ctrl+0       | 画布缩放复位至完整显示图像                                   |

**删除确认：** 删除选中标注 / 清空标注 / 删除图片及标注 三类操作均先弹确认框，可勾选 **"不再提醒"**（按操作类型分别记忆，勾选后该类操作不再弹框）。

**画布右键菜单**（编辑模式、无绘制草稿时）：对象命中区提供 编辑属性 / 删除 / 复制 / 粘贴；空白处提供 撤销 / 重做；并含 创建矩形 / 创建点 / 创建多边形 / 编辑模式 / 清空标注 切换项，按当前状态自动启用或禁用。

### 6.4 Delete 键的焦点路由

Delete 快捷键按当前焦点控件自动路由：

| 焦点位置       | 行为                                             |
| -------------- | ------------------------------------------------ |
| 文本输入框     | 不拦截，执行正常文本删除                         |
| 对象列表       | 删除列表选中的对象（含关键点，支持多选批量删除） |
| 文件列表       | 删除选中图片及标注（等同 Shift+Delete）          |
| 画布或其他区域 | 删除画布选中形状                                 |

## 7. 右侧信息栏

右侧信息栏为单一**"对象面板"**停靠窗口（可浮动成独立小窗、自由移动、拖回停靠或关闭，面板整体宽度经分隔条拖拽自由调节），内部以垂直分隔条分为 标签列表 / 对象列表 / 文件列表 三个分区：分区分隔条可拖拽调节各分区高度；视图菜单的 **显示对象面板** 开关控制面板整体显隐，**显示标签列表 / 显示对象列表 / 显示文件列表** 三个开关分别控制各分区显隐；分区高度与面板布局自动持久化（下次启动恢复）。

| 面板         | 说明                                                                                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **标签列表** | 当前工作路径的全部标签（按字母序），每项带类别颜色圆点；单击/双击即设为当前绘制标签                                                                                  |
| **对象列表** | 当前图片的全部标注对象（含关键点），显示 `标签 [组号]`（有分组时）；支持多选、可见性复选框（取消勾选仅隐藏渲染不删数据）、右键菜单（编辑/删除/进入编辑模式）         |
| **文件列表** | 工作路径全部图片，带只读"已标注"复选框（保存后自动勾选）；顶部检索框按文件名/标签/已标注状态实时过滤；单击切换当前图片，**双击快捷编辑**（加载该图片并进入编辑模式） |

对象列表与画布双向联动：列表选中 ⇔ 画布选中（含多选）；画布选中变化自动同步列表。

**标签颜色：** 颜色按标签名分配，每个标签拥有唯一颜色（列表圆点、画布描边/填充/文本一致）；画布标签文本带投影，浅色背景图像上同样可辨识。

**标签来源规则：** 标签列表 = 扫描结果 ∪ 已浏览图片中的标签。浏览图片时标签自动累加（保留原始拼写）；执行"扫描并统计"后由扫描结果统一合并大小写同名标签。

| 填充不透明度 | 10% / 20% / 30% / 50% / 70%（互斥单选）                                         |
| 字体大小     | 10 / 12 / 14 / 16 / 20（互斥单选）                                              |
| 关键点大小   | 3 / 4 / 5 / 6 / 8（互斥单选，控制关键点圆点半径，半径为场景单位、跟随图像缩放） |

**画布缩放：** 按住 **Ctrl + 滚轮** 以光标位置为锚点缩放（步长 1.12，倍率约 0.05~40 倍）；无修饰键滚轮为垂直滚动浏览（放大后可上下浏览图像）。**视图 → 适应窗口**（Ctrl+0）将缩放复位至完整显示图像。

## 9. 统计（统计菜单）

| 菜单项     | 说明                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 扫描并统计 | 对当前工作目录启动后台扫描：弹出非模态进度对话框（可随时中止），完成后弹出 **"标签统计"** 窗口 |
| 自动扫描   | 勾选后每次打开文件夹自动执行扫描统计（默认关闭，偏好持久化）                                   |

**标签统计窗口** 内容：扫描目录、汇总行（`标签种类 N 种 · 实例总数 M 个 · 标注文件 K 个`）、两列表格（标签 / 实例个数，按实例数降序）。大小写不同的同名标签（`person` 与 `Person`）合并为一行。

扫描结果同时缓存，供 **导出标注** 对话框自动预填类别列表、关键点列表与任务类型。

## 10. 自动标注

### 10.1 加载模型 / 自动标注设置

入口：**工具 → 加载模型 / 自动标注设置**。对话框包含四张卡片：

**运行设备**

- **GPU（推荐）：** 检测到 CUDA 环境时默认选中；未检测到时禁用并回退 CPU。
- **CPU：** ONNX Runtime CPU 推理，兼容无 NVIDIA 显卡的机器。

**模型**

| 设置项   | 说明                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 模型路径 | 选择 `.onnx` 或 `.engine` 模型文件                                                                                       |
| 任务类型 | 目标检测 / 姿态估计 / 实例分割 / 文字识别（OCR）。选择模型后自动按模型元数据推导并**锁定**；无法识别时解锁由用户手动选择 |
| 识别模型 | 仅 OCR 模式显示：选择识别模型 `.onnx` 文件（模型路径此时为检测模型）                                                     |
| 识别字典 | 仅 OCR 模式显示：选择识别字典 `.txt` 文件（须与识别模型训练字典一致，加载时自动校验字符表长度）                          |

**OCR 智能引导：** OCR 模式下模型路径行标签切换为"检测模型"。误将识别模型选入检测模型字段（或反之）时自动归位到对应字段并提示；模型卡底部状态行实时显示配置齐全状态（检测 / 识别 / 字典），缺项橙色提示、齐全绿色提示。

**检测类别**

- 选择模型后自动解析模型元数据中的类别，以复选框列出（显示 `类别id: 类别名`），默认**全选**。
- 全部勾选等价于不过滤；全部取消勾选（或模型无类别元数据）时检测所有类别。
- 顶部实时显示"已选 X / 共 Y 个类别"，右上角提供 **全选 / 取消全选** 一键切换。

**推理参数**

| 参数         | 默认值 | 说明                                           |
| ------------ | ------ | ---------------------------------------------- |
| BBox 置信度  | 0.25   | 检测框置信度阈值，越高检出越严格               |
| NMS          | 0.7    | 非极大值抑制阈值（重框去重）                   |
| 关键点置信度 | 0.5    | 仅姿态估计任务显示；低于该值的关键点记为 0 0 0 |

点击 **保存设置** 后生效。GPU 模式下选择了 `.onnx` 模型时，程序会弹窗确认是否转换为 TensorRT engine（转换在后台执行，已有同名 `.engine` 时直接复用不重复转换）。

### 10.2 标注当前图片

入口：**工具 → 标注当前图片**。对画布当前图片执行推理，期间弹出**模态进度窗口**（进度条 + 日志 + 可中止），完成后结果自动回填画布（未保存状态），可人工修正后保存。

### 10.3 标注所有图片

入口：**工具 → 标注所有图片**。对工作路径全部图片批量推理，输出与图片同目录的同名 `.json` 标注文件。

若检测到已有标注文件，弹出 **"自动标注选项"**：

- **跳过已标注的图片**（默认）：仅标注尚无标注文件的图片。
- **重新标注并覆盖**：删除原标注文件后全部重新生成（避免无检测结果时残留旧标注）。

中断恢复（断点续传）：批量标注逐图片落盘，中止或异常后重跑同任务并选择 **跳过已标注的图片**，即从断点继续标注剩余图片（所有任务类型含 OCR 均适用）。

### 10.4 标注视频

入口：**工具 → 标注视频**。打开独立的 **"标注视频"** 窗口：

| 设置项       | 说明                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 输入路径     | 视频所在目录（默认为主窗口当前工作目录），支持 mp4/avi/mov                   |
| 输出路径     | 抽帧图片与标注输出目录，**默认为 `输入路径/Output`**；手动改过后不再自动跟随 |
| 抽帧间隔(帧) | 每隔多少帧抽取一帧，范围 1~10000，**默认 10**                                |

- **视频列表：** 目录下视频文件动态分批扫描入列（大目录不卡界面），复选框勾选参与标注的视频，默认全选，提供 全选/取消全选 按钮。
- **预览播放器：** 点击视频即可预览；支持 播放/暂停、后退 1s / 快进 1s、变速（0.25x / 0.5x / 1x / 2x / 4x）、进度滑块拖动定位、时间显示。
- **损坏视频保护：** 无法读取帧或连续 5 帧画面停滞时自动终止该视频的标注，防止死循环。
- 点击 **开始标注** 后弹出模态进度窗口（可中止）。

**抽帧输出命名：** `视频名_frame序号.jpg`（序号 6 位补零），如 `video1_frame000010.jpg`；标注 JSON 与抽帧图片同名同目录。

**断点续传：** 已抽帧的图片不重复写盘，已存在标注 JSON 的帧自动跳过标注——视频标注中断后重跑同任务即从断点继续。

### 10.5 标注收尾

- 图片批量标注完成后自动刷新文件列表的"已标注"状态并重载当前图片。
- 视频标注完成后自动重新扫描工作目录，纳入新增抽帧图片。

## 11. 导出标注（JSON → 数据集）

入口：**工具 → 导出标注**。打开前置检查：必须已打开工作路径，且其中包含图片与 LabelMe JSON 标注（不满足时弹窗拦截，不弹出对话框）。

| 设置项                   | 说明                                                                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 工作路径                 | 只读显示当前工作路径（源目录固定，源格式锁定 LabelMe）                                                                                   |
| 任务类型                 | 目标检测 / 姿态估计 / 实例分割 / 文字识别（OCR）                                                                                         |
| 输出目录                 | 转换结果保存目录                                                                                                                         |
| 训练集/验证集/测试集比例 | 默认 0.8 / 0.1 / 0.1（三者之和应为 1.0），仅导出方向显示                                                                                 |
| 导出 YOLO 数据集目录结构 | 勾选后按 `images/`、`labels/` 目录结构导出并按比例划分数据集，仅 DETECT/POSE/SEGMENT 导出方向显示（OCR 导出 PPOCR 标注结构不适用）       |
| 生成识别数据集 (rec)     | 仅 OCR 导出显示：同时透视裁剪文本行图并生成 `rec_gt.txt` 识别标注                                                                        |
| 字典包含空格字符         | 仅 OCR 导出显示：`dict.txt` 末尾追加空格字符行（对应 use_space_char）                                                                    |
| 可视化标注结果           | 勾选后在输出目录生成标注可视化图片，便于核对                                                                                             |
| 类别列表                 | 拖拽排序，行首数字 = 转换后类别 id（从 0 开始）；支持"一键分析数据集"自动填充                                                            |
| 关键点列表               | 仅姿态估计显示，名称须以 `_point{序号}` 结尾（如 `nose_point0`）                                                                         |
| 一键分析数据集           | 自动识别目录层级、标注格式、任务类型（附形状统计）并提取标签填充类别列表；OCR 数据集（box 类形状过半携带非空文本内容）自动推断为文字识别 |
| 导入/导出配置            | 将当前设置保存为 JSON 复用（`convert_config.json`）                                                                                      |

点击 **开始转换** 后进度条与日志实时显示，**停止** 可随时中断。校验规则：类别列表为空、工作路径无 JSON 标注时弹窗拦截。

**标签格式校验：** 导出时逐文件校验 TXT 行格式（DETECT：`classid x y x y` 5 列；POSE：`5+3×kpt` 列；SEGMENT：`5+2n` 列），非法文件归档到输出目录的 `failed/` 子目录并记录日志，不影响其余文件。

**OCR 导出（JSON → PaddleOCR）：** 任务类型选"文字识别 (OCR)"后，输出目录生成可直接用于 PaddleOCR 训练的数据集：

| 输出                         | 说明                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| `images/`                    | 复制的源图片                                                                               |
| `det_gt.txt`                 | 检测标注：每行 `images/xxx.jpg\t[{"transcription": 文本, "points": 四点, "difficult": …}]` |
| `rec_gt.txt` + `rec_images/` | 识别标注与透视裁剪的文本行图（勾选"生成识别数据集"时）                                     |
| `dict.txt`                   | 自动字符字典（全部文本按首次出现顺序去重；按需尾追加空格字符）                             |
| `visualize/`                 | 可视化（勾选"可视化标注结果"时）：四点框描边 + 文本内容，便于人工校验                      |

**困难样本标记：** 形状属性对话框（绘制完成或对象列表编辑）中可勾选"困难样本 (difficult)"，导出时写入对应标注元素的 `difficult` 字段；老 JSON 文件无该字段按 false 处理。

## 12. 导入标注（数据集 → JSON）

入口：**工具 → 导入标注(非json格式->json)**。

| 设置项             | 说明                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| 输入目录           | YOLO TXT 或 PaddleOCR det 标注与图片所在目录                                       |
| 输出目录           | LabelMe JSON 输出目录                                                              |
| 文件列表与图像预览 | 仅导入方向显示；点击文件预览图像，支持 ◀ 上一张 / 下一张 ▶ 与 **A / D 快捷键**切换 |

**OCR 导入（PaddleOCR det → JSON）：** 任务类型选"文字识别 (OCR)"后，输入目录下的 det 标注 txt（每行 `图片路径\t[{"transcription", "points", "difficult"}, ...]`）逐行转换为 LabelMe JSON：每框为 polygon 四点形状，文本内容写入 description、困难标记写入 difficult 字段；对应图片一并复制到输出目录（`rec_gt*.txt` 与 `dict.txt` 自动排除）。

类别列表与关键点列表同样参与反查（TXT 不含标签名，按类别 id 反查类别列表填入 JSON）；"一键分析数据集"可自动推断方向、任务类型并填充类别（TXT 无标签时按类别索引 0,1,2… 自动填充）。

**导入完成后，程序自动将输出目录作为新的工作路径打开**，可直接继续人工标注。

## 14. 常见问题（FAQ）

**Q1：界面提示"未检测到 CUDA，仅支持 CPU"？**

GPU 选项被禁用说明 TensorRT 或 CUDA 相关组件不可用。请确认使用的是 GPU 版安装包，且已安装 NVIDIA 显卡驱动。CPU 版安装包不含 GPU 组件，属正常现象。

**Q2：GPU 模式下选择 ONNX 模型后弹窗提示转换 engine？**

GPU 推理使用 TensorRT engine 模型。首次使用 ONNX 模型时程序会请求确认转换为 engine（约 10~30 分钟），转换结果保存在模型同目录；此后加载自动复用。若取消转换，启动标注时会提示需先完成转换。

**Q3：检测类别列表显示"未提供类别信息"？**

所选模型的元数据中不含类别数据。此时不做类别过滤，将检测模型支持的所有类别。如需按类别过滤，请使用带类别元数据导出的 YOLO 系 ONNX 模型，或重新用工具转换一次模型。

**Q4：选择 `.engine` 模型后类别列表显示"未提供类别信息"？**

程序优先读取 engine 文件内嵌元数据；为空说明该 engine 由旧版本程序转换、未写入元数据，且同目录下无同名 `.onnx` 可回退。重新转换一次模型即可恢复类别选择功能。

**Q5：自动标注结果中部分类别缺失？**

请检查 **检测类别** 卡片中对应类别是否勾选。只有勾选的类别才会写入标注文件。

**Q6：GPU 推理速度没有明显提升？**

请确认运行设备选择了 GPU，且使用的是 engine 模型（进度日志中会显示模型路径）。

**Q7：导出标注时部分文件被归档到 `failed/` 目录？**

这些文件的标注格式未通过校验（如标签列数不符合当前任务类型、类别 id 超出类别列表范围等）。修正后在导出日志中可查看具体原因，重新导出即可。

**Q8：删除了图片/标注还能恢复吗？**

"删除图片及标注"与"重新标注并覆盖"均会**直接删除文件**（删除前默认弹确认框，可勾选"不再提醒"），删除后无回收站可恢复，请谨慎操作并提前备份重要数据。
