## 1. 产品概述

BrilliantAnnotator 是一款基于深度学习模型的智能数据标注工具，采用 labelme 风格的三栏式标注编辑器布局（顶部工具栏 / 中央画布 / 右侧信息栏），标注数据完全兼容 LabelMe JSON 格式。核心功能：

| 功能              | 说明                                                                                     |
| ----------------- | ---------------------------------------------------------------------------------------- |
| **人工标注编辑**  | 矩形 / 点 / 多边形三种标注工具，支持对象属性（标签/描述/分组）、复制粘贴、撤销重做、多选 |
| **感知区（ROI）** | 画布绘制与管理感知区（虚线框 + `ROI{id}` 标识），支持按感知区裁剪导出聚焦数据集          |
| **自动标注**      | 加载 ONNX 模型，对单张图片、全部图片、视频批量推理，自动生成 LabelMe 标注                |
| **格式转换**      | 导出（LabelMe JSON → YOLO TXT，含数据集划分）与导入（YOLO TXT → LabelMe JSON）双向转换   |
| **数据集统计**    | 后台扫描工作目录标注文件，汇总标签种类、实例个数与标注形状分布                           |
| **更新与帮助**    | 在线检查更新（Gitee Release）、内置本说明书查看器                                        |

支持的任务模式：

| 任务模式            | 自动标注 | 格式转换 |
| ------------------- | -------- | -------- |
| 目标检测（DETECT）  | 支持     | 支持     |
| 姿态估计（POSE）    | 支持     | 支持     |
| 实例分割（SEGMENT） | 支持     | 支持     |
| 文字识别（OCR）     | 支持     | 支持     |

## 2. 系统要求

| 项目     | 要求                                                     |
| -------- | -------------------------------------------------------- |
| 操作系统 | Windows 10 / 11（64 位）                                 |
| CPU 版   | 无特殊要求，4 GB 以上内存                                |
| GPU 版   | NVIDIA 显卡 + 已安装显卡驱动；GPU 推理需自备 CUDA 运行库 |
| 磁盘空间 | 安装空间视版本而定（GPU 版较大），输出目录预留足够空间   |

**GPU 版说明：**

- GPU 推理基于 onnxruntime CUDA Execution Provider，**无需转换模型**（直接使用 `.onnx`）。
- 安装包不内置 CUDA 运行库，请自行安装 **CUDA Toolkit 12.9 + cuDNN 9.x**，并确保 cuDNN 的 `bin` 目录在系统 PATH 中（或通过 conda 安装对应 nvidia 组件）。
- 启动时程序自动检测 CUDA 可用性：检测失败时"运行设备"中的 GPU 选项被禁用并回退 CPU（不崩溃，仅推理变慢）；**CPU 版安装包跳过该检测**，始终仅提供 CPU 模式。

## 3. 安装与启动

### 3.1 安装器安装

1. 双击安装程序（如 `BrilliantAnnotator_Setup_GPU.exe`）。
2. 按向导提示选择安装目录，完成安装。
3. 从开始菜单或桌面快捷方式启动程序。

> 在线安装器在安装过程中自动下载并校验分卷压缩包，安装完成后自动清理临时文件；也可使用离线安装器（内置完整包）。

### 3.2 开发环境运行（源码）

```bash
conda create -n BrilliantAnnotator python=3.12.10
conda activate BrilliantAnnotator
pip install -r requirements.txt
python -m smart_annotator
```

## 4. 界面总览

程序主窗口为 **三栏式标注编辑器**：

| 区域           | 内容                                                                                                                                                                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **菜单栏**     | 文件 / 编辑 / 视图 / 工具 / 感知区 / 统计 / 帮助 七个菜单                                                                                                                                                                                             |
| **图标工具栏** | 菜单栏下方的图标按钮组（悬停显示功能与快捷键）：文件操作组（打开文件夹/打开文件/保存/另存为/删除选中/删除图片文件/适应窗口）+ 标注工具组（编辑/矩形/点/多边形/感知区，互斥选中）+ OCR 仅识别开关（仅 OCR 任务显示）；自定义改键后按钮悬停提示自动同步 |
| **中间画布**   | 图像显示与标注绘制/编辑区；Ctrl+滚轮以光标为锚缩放，无修饰键滚轮垂直滚动浏览（放大后可浏览图像）                                                                                                                                                      |
| **右侧信息栏** | 四个独立停靠窗口：标签列表 / 对象列表 / 文件列表 / 感知区列表；每个停靠窗口可浮动成独立小窗、自由移动、拖回停靠或关闭                                                                                                                                 |
| **状态栏**     | 显示当前图片序号（如 `3/120`）、文件名与未保存标记（`（未保存）`）                                                                                                                                                                                    |

- 右侧停靠窗口的堆叠高度经 Dock 之间的分隔条拖拽调节，挂靠宽度经其与画布之间的分隔条拖拽调节；面板布局（位置/尺寸/显隐）自动持久化（下次启动恢复）。
- 界面配置持久化于 `%APPDATA%/BrilliantAnnotator/render_config.json`（含自动保存、自动扫描、自动导出感知区等开关）。
- 未打开图片时，编辑相关功能自动禁用。

## 5. 文件操作（文件菜单 / 图标工具栏）

| 操作       | 入口                              | 说明                                                                                                     |
| ---------- | --------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 打开文件夹 | 文件 → 打开文件夹（Ctrl+O）       | 选择目录后自动扫描其中图片（jpg/jpeg/png/bmp），并加载第一张                                             |
| 打开文件   | 文件 → 打开文件（Ctrl+Shift+O）   | 打开单个图片或 LabelMe JSON 标注（标注会自动关联同名/同目录图片）                                        |
| 保存       | 文件 → 保存（Ctrl+S）             | 将当前标注（含感知区）写入与图片同名（扩展名 `.json`）的 LabelMe 标注文件                                |
| 另存为     | 文件 → 另存为（Ctrl+Shift+S）     | 选择目标路径保存当前标注                                                                                 |
| 自动保存   | 文件 → 自动保存（勾选，默认开启） | 开启后每次切换图片前自动保存当前标注；无修改且无标注文件时不产生空文件；勾选状态自动记忆（下次启动恢复） |

**未保存提醒：** 当前标注存在未保存修改时，切换图片、打开新目录/单图/标注文件、关闭程序前均会弹出提醒（**保存 / 不保存 / 取消** 三选，取消则中断切换）；开启自动保存时改为静默自动保存，不再弹框。

**删除图片及标注：** 入口 编辑 → 删除图片及标注（Shift+Delete），删除当前图片与其同名标注文件（弹确认框，可勾选"不再提醒"），并自动加载下一张。

## 6. 人工标注

### 6.1 标注工具

图标工具栏/工具菜单提供五种互斥工具（括号内为快捷键）：

| 工具   | 快捷键     | 说明                                                                                          |
| ------ | ---------- | --------------------------------------------------------------------------------------------- |
| 编辑   | V / Ctrl+E | 编辑模式：选中、拖拽移动、端点缩放、修改属性                                                  |
| 矩形   | R          | 点击两个对角点绘制矩形框                                                                      |
| 点     | P          | 单击放置关键点；关键点渲染为白描边实心圆点，大小可在 视图 → 关键点大小 调节，半径跟随图像缩放 |
| 多边形 | G          | 逐点点击绘制多边形，闭合后完成                                                                |
| 感知区 | O          | 绘制/编辑感知区（ROI）裁剪框，详见第 13 章                                                    |

**绘制辅助线：** 矩形 / 多边形绘制过程中，光标位置显示贯穿画布边缘的虚线十字延长线（便于对齐已有对象）；点工具不显示延长线（十字光标由鼠标指针提供）。绘制工具下鼠标指针为十字准星。

### 6.2 绘制流程与属性弹窗

绘制完成（矩形第二点点击 / 多边形闭合 / 点放置）后弹出 **"标注对象属性"** 窗口：

- **标签：** 输入框即时过滤下方已有标签列表；单击选择、双击选择并确认，也可直接键入新标签。
- **Group ID：** 可编辑下拉框，下拉项为当前画布已有组号（去重升序），也可键入新值；留空表示不分组。
- **描述：** 输入框填写备注（可选）。
- **困难样本 (difficult)：** 勾选后导出时写入该元素的困难标记（用于训练筛选）。
- **取消或标签为空：** 该形状不生效（静默丢弃，状态栏提示"未设置标签"）。

### 6.3 编辑操作（编辑菜单 / 画布右键菜单）

| 操作           | 快捷键       | 说明                                                            |
| -------------- | ------------ | --------------------------------------------------------------- |
| 撤销           | Ctrl+Z       | 撤销上一步绘制/编辑（含感知区增删改）；多边形绘制中撤回上一顶点 |
| 重做           | Ctrl+Shift+Z | 重做（多边形绘制中忽略）                                        |
| 复制           | Ctrl+C       | 复制画布选中对象到画布内部剪贴板                                |
| 粘贴           | Ctrl+V       | 粘贴剪贴板中的对象                                              |
| 删除选中标注   | Delete       | 按焦点上下文路由（见 6.4）；弹确认框，可勾选"不再提醒"          |
| 清空标注       | —            | 清空当前图片全部标注（弹确认框，可勾选"不再提醒"；不可恢复）    |
| 删除图片及标注 | Shift+Delete | 删除当前图片文件与其标注文件（弹确认框，可勾选"不再提醒"）      |
| 适应窗口       | Ctrl+0       | 画布缩放复位至完整显示图像                                      |

**删除确认：** 删除选中标注 / 清空标注 / 删除感知区 / 删除图片及标注 等操作均先弹确认框，可勾选 **"不再提醒"**（按操作类型分别记忆，勾选后该类操作不再弹框；重启恢复默认提醒）。

**画布右键菜单**（无绘制草稿时）：对象命中区提供 编辑属性 / 删除 / 复制 / 粘贴 / 转换为感知区（仅命中矩形标注时可用）；空白处提供 撤销 / 重做；并含 创建矩形 / 创建点 / 创建多边形 / 创建感知区 / 编辑模式 / 清空标注 切换项，按当前状态自动启用或禁用。

### 6.4 Delete 键的焦点路由

Delete 快捷键按当前焦点控件自动路由：

| 焦点位置         | 行为                                             |
| ---------------- | ------------------------------------------------ |
| 文本输入框       | 不拦截，执行正常文本删除                         |
| 对象列表         | 删除列表选中的对象（含关键点，支持多选批量删除） |
| 文件列表         | 删除选中图片及标注（等同 Shift+Delete）          |
| 感知区列表       | 删除列表中选中的感知区（弹确认框）               |
| 感知区工具下画布 | 删除画布中选中的感知区（弹确认框）               |
| 画布或其他区域   | 删除画布选中形状                                 |

## 7. 右侧信息栏

右侧为四个独立停靠窗口（可分别浮动成小窗、自由移动、拖回停靠或关闭），视图菜单的 **显示标签列表 / 显示对象列表 / 显示文件列表 / 显示感知区列表** 四个开关分别控制其显隐；布局自动持久化（下次启动恢复）。

| 面板           | 说明                                                                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **标签列表**   | 当前工作路径的全部标签（按字母序），每项带类别颜色圆点；单击/双击即设为当前绘制标签                                                                                              |
| **对象列表**   | 当前图片的全部标注对象（含关键点），显示 `标签 [组号]`（有分组时）；支持多选、可见性复选框（取消勾选仅隐藏渲染不删数据）、右键菜单（编辑/删除/进入编辑模式）、双击编辑、拖拽排序 |
| **文件列表**   | 工作路径全部图片，带只读"已标注"复选框（保存后自动勾选）；顶部检索框按文件名/标签/已标注状态实时过滤；单击切换当前图片，**双击快捷编辑**（加载该图片并进入编辑模式）             |
| **感知区列表** | 当前图片的全部感知区，行如 `ROI1  (120, 80) - (640, 480)  520×400`；单击选中并高亮画布对应感知区，双击定位（视图缩放至该区域），右键菜单 定位 / 删除（详见 13.3）                |

对象列表与画布双向联动：列表选中 ⇔ 画布选中（含多选）；画布选中变化自动同步列表。

**标签颜色：** 颜色按标签名分配，每个标签拥有唯一颜色（列表圆点、画布描边/填充/文本一致）；画布标签文本带投影（阴影不透明度可在视图菜单调节），浅色背景图像上同样可辨识。

**标签来源规则：** 标签列表 = 扫描结果 ∪ 已浏览图片中的标签。浏览图片时标签自动累加（保留原始拼写）；执行"扫描并统计"后由扫描结果统一合并大小写同名标签。

## 9. 统计（统计菜单）

| 菜单项     | 说明                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 扫描并统计 | 对当前工作目录启动后台扫描：弹出非模态进度对话框（可随时中止），完成后弹出 **"标签统计"** 窗口 |
| 自动扫描   | 勾选后每次打开文件夹自动执行扫描统计（默认关闭，偏好持久化）                                   |

**标签统计窗口** 内容：扫描目录、汇总行（`标签种类 N 种 · 实例总数 M 个 · 标注文件 K 个`）、两列表格（标签 / 实例个数，按实例数降序）。大小写不同的同名标签（`person` 与 `Person`）合并为一行。感知区（ROI）不参与统计。

扫描结果同时缓存，供 **导出标注** 对话框自动预填类别列表、关键点列表与任务类型。

## 10. 自动标注

### 10.1 加载模型 / 自动标注设置

入口：**工具 → 加载模型 / 自动标注设置**。对话框包含四张卡片：

**运行设备**

- **GPU（推荐）：** 检测到 CUDA 环境时默认选中；未检测到时禁用并回退 CPU（CPU 版安装包始终禁用）。
- **CPU：** ONNX Runtime CPU 推理，兼容无 NVIDIA 显卡的机器。

**模型**

| 设置项   | 说明                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 模型路径 | 选择 `.onnx` 模型文件（GPU 模式经 onnxruntime CUDA EP 推理，无需模型转换）                                               |
| 任务类型 | 目标检测 / 姿态估计 / 实例分割 / 文字识别（OCR）。选择模型后自动按模型元数据推导并**锁定**；无法识别时解锁由用户手动选择 |
| 识别模型 | 仅 OCR 模式显示：选择识别模型 `.onnx` 文件（模型路径此时为检测模型）                                                     |
| 识别字典 | 仅 OCR 模式显示：选择识别字典 `.txt` 文件（须与识别模型训练字典一致，加载时自动校验字符表长度）                          |

**OCR 智能引导：** OCR 模式下模型路径行标签切换为"检测模型"。误将识别模型选入检测模型字段（或反之）时自动归位到对应字段并提示；模型卡底部状态行实时显示配置齐全状态（检测 / 识别 / 字典），缺项橙色提示、齐全绿色提示。

**检测类别**

- 选择模型后自动解析模型元数据中的类别，以复选框列出（显示 `类别id: 类别名`），默认**全选**。
- 全部勾选等价于不过滤；全部取消勾选（或模型无类别元数据）时检测所有类别。
- 顶部实时显示"已选 X / 共 Y 个类别"，右上角提供 **全选 / 取消全选** 一键切换。

**推理参数**

| 参数         | 默认值 | 说明                                                                |
| ------------ | ------ | ------------------------------------------------------------------- |
| BBox 置信度  | 0.25   | 检测框置信度阈值，越高检出越严格（OCR 模式隐藏）                    |
| NMS          | 0.7    | 非极大值抑制阈值（重框去重，OCR 模式隐藏）                          |
| 关键点置信度 | 0.5    | 仅姿态估计任务显示；低于该值的关键点记为 0 0 0                      |
| 二值化阈值   | 0.2    | 仅 OCR 显示：DB 文本检测概率图二值化阈值                            |
| 检测框置信度 | 0.45   | 仅 OCR 显示：文本框平均分过滤阈值                                   |
| 外扩比例     | 1.4    | 仅 OCR 显示：文本框 unclip 外扩比例                                 |
| 仅识别       | 不勾选 | 仅 OCR 显示：跳过文本检测，仅对已标注 shape 区域执行识别（见 10.6） |

点击 **保存设置** 后生效。模型确认后立即在后台加载并预热（弹出进度窗实时显示加载/预热阶段），首次加载完成后再次使用同一模型秒级启动，无需重复等待。

### 10.2 标注当前图片

入口：**工具 → 标注当前图片**（Ctrl+1）。对画布当前图片执行推理，期间弹出**模态进度窗口**（进度条 + 日志 + 可中止/暂停），完成后结果自动回填画布（未保存状态），可人工修正后保存。

### 10.3 标注所有图片

入口：**工具 → 标注所有图片**（Ctrl+2）。对工作路径全部图片批量推理，输出与图片同目录的同名 `.json` 标注文件。

若检测到已有标注文件，弹出 **"自动标注选项"**：

- **跳过已标注的图片**（默认）：仅标注尚无标注文件的图片。
- **重新标注并覆盖**：删除原标注文件后全部重新生成（避免无检测结果时残留旧标注）；**原文件中的感知区（ROI）字段会被保留**。

中断恢复（断点续传）：批量标注逐图片落盘，中止或异常后重跑同任务并选择 **跳过已标注的图片**，即从断点继续标注剩余图片（所有任务类型含 OCR 均适用）。

### 10.4 标注视频

入口：**工具 → 标注视频**。打开独立的 **"标注视频"** 窗口：

| 设置项       | 说明                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 输入路径     | 视频所在目录（默认为主窗口当前工作目录），支持 mp4/avi/mov                   |
| 输出路径     | 抽帧图片与标注输出目录，**默认为 `输入路径/Output`**；手动改过后不再自动跟随 |
| 抽帧间隔(帧) | 每隔多少帧抽取一帧，范围 1~10000，**默认 10**                                |

- **视频列表：** 目录下视频文件动态分批扫描入列（大目录不卡界面），复选框勾选参与标注的视频，默认全选，提供 全选/取消全选 按钮。
- **预览播放器：** 点击视频即可预览；支持 播放/暂停、后退 1s / 快进 1s、变速（0.25x / 0.5x / 1x / 2x / 4x）、进度滑块拖动定位、时间显示。
- **损坏视频保护：** 无法读取帧或连续 5 帧画面停滞时自动终止该视频的标注，防止死循环。
- 点击 **开始标注** 后弹出模态进度窗口（可中止）；中断后再次进入会恢复上次的路径与抽帧设置。

**抽帧输出命名：** `视频名_frame序号.jpg`（序号 6 位补零），如 `video1_frame000010.jpg`；标注 JSON 与抽帧图片同名同目录。

**断点续传：** 已抽帧的图片不重复写盘，已存在标注 JSON 的帧自动跳过标注——视频标注中断后重跑同任务即从断点继续。

### 10.5 标注收尾

- 图片批量标注完成后自动刷新文件列表的"已标注"状态并重载当前图片。
- 视频标注完成后自动重新扫描工作目录，纳入新增抽帧图片。

### 10.6 OCR 仅识别

"仅识别"跳过文本检测阶段，直接对**已标注区域**（shape 框内）执行文字识别，识别结果回写为对应形状的文本内容与置信度。两种使用方式：

| 方式           | 入口                                                   | 说明                                               |
| -------------- | ------------------------------------------------------ | -------------------------------------------------- |
| 开关（批量）   | 模型设置 → 推理参数 → 仅识别；或工具栏"OCR 仅识别"按钮 | 勾选后，"标注当前图片/所有图片"按仅识别语义执行    |
| 快捷键（单张） | **Ctrl+R**（或 工具 → OCR 仅识别（当前图片））         | 对当前画布图片强制执行一次仅识别（与开关状态无关） |

- 仅识别以**画布实时形状**为输入（未保存的删除/新增均以画布为准），仅支持 OCR 任务，其他任务会提示先加载 OCR 模型。
- 无标注区域的图片会被跳过并提示；识别结果为空时不会清空原有标注。

## 11. 导出标注（JSON → 数据集）

入口：**工具 → 导出标注**。打开前置检查：必须已打开工作路径，且其中包含图片与 LabelMe JSON 标注（不满足时弹窗拦截，不弹出对话框）。

| 设置项                   | 说明                                                                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 工作路径                 | 只读显示当前工作路径（源目录固定，源格式锁定 LabelMe）                                                                                   |
| 任务类型                 | 目标检测 / 姿态估计 / 实例分割 / 文字识别（OCR）                                                                                         |
| 输出目录                 | 转换结果保存目录                                                                                                                         |
| 训练集/验证集/测试集比例 | 默认 0.8 / 0.1 / 0.1（三者之和应为 1.0），仅导出方向显示                                                                                 |
| 导出 YOLO 数据集目录结构 | 勾选后按 `images/`、`labels/` 目录结构导出并按比例划分数据集，仅 DETECT/POSE/SEGMENT 导出方向显示（OCR 导出 PPOCR 标注结构不适用）       |
| 生成识别数据集 (rec)     | 仅 OCR 导出显示：同时透视裁剪文本行图并生成 `rec_gt.txt` 识别标注                                                                        |
| 字典包含空格字符         | 仅 OCR 导出显示：`dict.txt` 末尾追加空格字符行（对应 use_space_char）                                                                    |
| 可视化标注结果           | 勾选后在输出目录生成标注可视化图片，便于核对                                                                                             |
| 类别列表                 | 拖拽排序，行首数字 = 转换后类别 id（从 0 开始）；支持"一键分析数据集"自动填充                                                            |
| 关键点列表               | 仅姿态估计显示，名称须以 `_point{序号}` 结尾（如 `nose_point0`）                                                                         |
| 一键分析数据集           | 自动识别目录层级、标注格式、任务类型（附形状统计）并提取标签填充类别列表；OCR 数据集（box 类形状过半携带非空文本内容）自动推断为文字识别 |
| 导入/导出配置            | 将当前设置保存为 JSON 复用（`convert_config.json`）                                                                                      |

点击 **开始转换** 后进度条与日志实时显示，**停止** 可随时中断。校验规则：类别列表为空、工作路径无 JSON 标注时弹窗拦截。

**标签格式校验：** 导出时逐文件校验 TXT 行格式（DETECT：`classid x y x y` 5 列；POSE：`5+3×kpt` 列；SEGMENT：`5+2n` 列），非法文件归档到输出目录的 `failed/` 子目录并记录日志，不影响其余文件。

**OCR 导出（JSON → PaddleOCR）：** 任务类型选"文字识别 (OCR)"后，输出目录生成可直接用于 PaddleOCR 训练的数据集：

| 输出                         | 说明                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| `images/`                    | 复制的源图片                                                                               |
| `det_gt.txt`                 | 检测标注：每行 `images/xxx.jpg\t[{"transcription": 文本, "points": 四点, "difficult": …}]` |
| `rec_gt.txt` + `rec_images/` | 识别标注与透视裁剪的文本行图（勾选"生成识别数据集"时）                                     |
| `dict.txt`                   | 自动字符字典（全部文本按首次出现顺序去重；按需尾追加空格字符）                             |
| `visualize/`                 | 可视化（勾选"可视化标注结果"时）：四点框描边 + 文本内容，便于人工校验                      |

**困难样本标记：** 形状属性对话框（绘制完成或对象列表编辑）中可勾选"困难样本 (difficult)"，导出时写入对应标注元素的 `difficult` 字段；老 JSON 文件无该字段按 false 处理。

## 12. 导入标注（数据集 → JSON）

入口：**工具 → 导入标注(非json格式->json)**。

| 设置项             | 说明                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| 输入目录           | YOLO TXT 或 PaddleOCR det 标注与图片所在目录                                       |
| 输出目录           | LabelMe JSON 输出目录                                                              |
| 文件列表与图像预览 | 仅导入方向显示；点击文件预览图像，支持 ◀ 上一张 / 下一张 ▶ 与 **A / D 快捷键**切换 |

**OCR 导入（PaddleOCR det → JSON）：** 任务类型选"文字识别 (OCR)"后，输入目录下的 det 标注 txt（每行 `图片路径\t[{"transcription", "points", "difficult"}, ...]`）逐行转换为 LabelMe JSON：每框为 polygon 四点形状，文本内容写入 description、困难标记写入 difficult 字段；对应图片一并复制到输出目录（`rec_gt*.txt` 与 `dict.txt` 自动排除）。

类别列表与关键点列表同样参与反查（TXT 不含标签名，按类别 id 反查类别列表填入 JSON）；"一键分析数据集"可自动推断方向、任务类型并填充类别（TXT 无标签时按类别索引 0,1,2… 自动填充）。

**导入完成后，程序自动将输出目录作为新的工作路径打开**，可直接继续人工标注。

## 13. 感知区（ROI）与裁剪导出

感知区用于标记图像的**关注区域**：既作为画布上的可视化参考框，也可按框裁剪生成聚焦的小图数据集（图片 + 对应标注，跨边界标注自动截断）。

### 13.1 数据格式（LabelMe 扩展字段）

感知区保存在标注 JSON 顶层 `ROI` 字段（与 `imagePath` / `imageWidth` / `imageHeight` 同级），**不进入 `shapes`**：

```json
"ROI": [
  { "id": 1, "box": [120, 80, 640, 480] },
  { "id": 2, "box": [660, 80, 1100, 480] }
]
```

- `box`：矩形坐标 `x1 y1 x2 y2`（图像像素、左上原点），读取时自动归一为左上/右下顺序
- `id`：同图内唯一正整数，从 1 自增、删除后不复用；画布标识文本为 `ROI{id}`
- **旧版兼容**：无 `ROI` 字段的 JSON 正常加载（视为无感知区）；感知区为空时不写该字段，老文件保存后不会新增键
- 一张图片可指定多个感知区，各自独立编号

### 13.2 绘制与编辑（感知区工具）

选择 **感知区工具**（工具栏"感知区"按钮 / 工具菜单"感知区" / 快捷键 **O**）后：

| 操作         | 说明                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------- |
| 绘制新感知区 | 在画布空白处按住左键拖拽出矩形，松开即创建（自动钳制在图像范围内；小于 4×4 像素丢弃并提示） |
| 选中         | 单击已有的虚线框内部，框体高亮并显示左上/右下端点手柄                                       |
| 移动         | 拖动框体内部，整体平移（不超出图像边界）                                                    |
| 缩放         | 拖动端点手柄调整大小（最小 4×4 像素）                                                       |
| 取消         | Esc：先取消绘制中的草稿，其次取消当前选中                                                   |
| 删除         | 选中后按 Delete（弹确认框）                                                                 |

- 感知区以**虚线矩形 + 左上角 `ROI{id}` 标识**渲染（青蓝色，与实线标注框/类别标签明显区分），绘制在标注形状下层，不遮挡标注内容。
- 非感知区工具下，感知区仅作展示，不会被鼠标命中，不影响既有标注的绘制/编辑/选择。
- 感知区的新建、删除、移动、缩放均可 **Ctrl+Z / Ctrl+Shift+Z** 撤销与重做。

**由矩形标注快速转换：**

- 入口一：选中一个或多个矩形标注 → 菜单 **感知区 → 从选中矩形标注创建感知区**（Ctrl+Shift+R），批量转换为感知区；
- 入口二：在画布上右键某个矩形标注 → **转换为感知区**（仅命中矩形标注时可用）。
- 转换后**原矩形标注保留**，新感知区与原框位置一致并自动选中。

### 13.3 感知区列表（右侧停靠窗口）

| 操作   | 说明                                                                        |
| ------ | --------------------------------------------------------------------------- |
| 查看   | 每行显示 `ROI{id}` 与坐标、尺寸，如 `ROI1  (120, 80) - (640, 480)  520×400` |
| 单击   | 选中并高亮画布中对应感知区                                                  |
| 双击   | 定位：视图缩放至该感知区区域                                                |
| 右键   | 定位 / 删除                                                                 |
| Delete | 焦点在列表时删除选中的感知区（弹确认框）                                    |

切换图片或画布上的感知区发生变化时，列表自动刷新。

### 13.4 手动导出感知区数据

入口：菜单 **感知区 → 手动导出感知区数据**（Ctrl+Shift+E）。弹窗设置：

| 设置项   | 说明                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 导出范围 | **当前图片**（默认）/ **全部图片**（批处理，工作路径下全部图片）；未打开图片时仅可选全部 |
| 输出目录 | 默认 `<工作路径>/ROI`，可点击"浏览..."更改，目录不存在时自动创建                         |

- 若当前图片有未保存修改，程序会**先自动保存**再导出（保证导出内容与标注文件一致）。
- 批量导出在后台线程执行，弹出模态进度窗口（显示当前处理文件，可中止）。
- 完成后弹窗汇总：图片总数/已处理数、导出感知区个数、跳过个数、无感知区图片数、失败数与错误摘要；输出目录下生成裁剪结果。
- 无感知区的图片会被跳过（不产生任何文件）。

### 13.5 自动导出感知区数据

菜单 **感知区 → 自动导出感知区数据**：勾选后，**每次保存标注**（含 Ctrl+S、另存为、自动保存）时，若当前图片存在感知区且已打开工作路径，自动把该图片的全部感知区裁剪导出到 `<工作路径>/ROI`。

- 勾选状态随配置持久化（下次启动恢复）。
- 导出失败不影响保存（仅记录日志并在状态栏提示原因）。

### 13.6 裁剪产物与标注截断规则

每个感知区输出两个文件到 `<工作路径>/ROI`（平铺存放）：

| 产物     | 命名                         | 说明                                                                        |
| -------- | ---------------------------- | --------------------------------------------------------------------------- |
| 裁剪图片 | `{原图名}_ROI{id}{原扩展名}` | 保持原图格式（jpg→jpg、png→png），JPEG 质量 95                              |
| 裁剪标注 | `{原图名}_ROI{id}.json`      | LabelMe 标准格式（`imagePath` 指向裁剪图、尺寸为裁剪尺寸，不含 `ROI` 字段） |

标注截断规则（原图标注 → 裁剪图标注，坐标平移至裁剪图左上角为原点）：

| 形状类型  | 规则                                                |
| --------- | --------------------------------------------------- |
| rectangle | 与感知区取交集；完全在框外则丢弃；宽或高为 0 则丢弃 |
| polygon   | 逐顶点钳制到感知区边界内；包围盒与框无交集则丢弃    |
| point     | 仅保留落在感知区内的点（含边界），框外的点丢弃      |
| 其他类型  | 按顶点钳制兜底                                      |

> 例：一个横跨感知区边界的检测框，导出后在裁剪标注中被截断为框内部分，坐标全部落在裁剪图范围内。

## 15. 常见问题（FAQ）

**Q1：界面提示"未检测到 CUDA，仅支持 CPU"？**

说明 onnxruntime 未提供 CUDA 执行提供器。请确认使用的是 GPU 版安装包、已安装 NVIDIA 显卡驱动，并且已安装 CUDA Toolkit 12.9 + cuDNN 9.x（cuDNN 的 `bin` 目录需在 PATH 中）。CPU 版安装包不含 GPU 组件，属正常现象。

**Q2：GPU 模式选择模型后没有转换过程，直接就能标注？**

是的。GPU 推理直接使用 `.onnx` 模型（onnxruntime CUDA EP），无需转换为 TensorRT engine，省去长时间转换等待；首次使用时后台加载并预热模型（进度窗显示），之后复用缓存秒级启动。

**Q3：检测类别列表显示"未提供类别信息"？**

所选模型的元数据中不含类别数据。此时不做类别过滤，将检测模型支持的所有类别。如需按类别过滤，请使用带类别元数据导出的 YOLO 系 ONNX 模型，或重新用工具转换一次模型。

**Q4：自动标注结果中部分类别缺失？**

请检查 **检测类别** 卡片中对应类别是否勾选。只有勾选的类别才会写入标注文件。

**Q5：重新执行"标注所有图片"会丢失感知区吗？**

不会。选择"重新标注并覆盖"时保留原标注文件中的 `ROI` 字段，仅重建 `shapes`；感知区数据不会因重新标注而丢失。

**Q6：导出的裁剪图片在哪里？标注为什么被截断？**

裁剪产物默认输出到 **工作路径下的 `ROI` 文件夹**（`{原图名}_ROI{id}.jpg/.png` 与同名 `.json`）。跨出感知区边界的标注框会按规则截断：矩形取与感知区的交集、多边形顶点钳制到边界内、框外的点丢弃，坐标平移到裁剪图范围内。

**Q7：导出标注时部分文件被归档到 `failed/` 目录？**

这些文件的标注格式未通过校验（如标签列数不符合当前任务类型、类别 id 超出类别列表范围等）。修正后在导出日志中可查看具体原因，重新导出即可。

**Q8：删除了图片/标注还能恢复吗？**

"删除图片及标注"与"重新标注并覆盖"均会**直接删除文件**（删除前默认弹确认框，可勾选"不再提醒"），删除后无回收站可恢复，请谨慎操作并提前备份重要数据。

**Q9：感知区在画布上挡住了标注？**

感知区绘制在标注形状的**下层**且为无填充虚线框，不会遮挡标注；若视觉上仍显拥挤，可在右侧"感知区列表"中删除或调整感知区范围，或临时关闭该停靠窗口。

**Q10：勾选了"自动导出感知区数据"，但保存后没有输出文件？**

请确认：① 已打开工作路径（导出目录为 `<工作路径>/ROI`）；② 当前图片存在感知区（右侧"感知区列表"非空）；③ 保存动作已成功执行（状态栏会提示"已自动导出 N 个感知区裁剪"或失败原因）。
