## 1. 产品概述

VAI_E_SmartAnnotator 是一款基于深度学习模型的智能数据标注工具，采用 labelme 风格的三栏式标注编辑器布局，标注数据完全兼容 LabelMe JSON 格式。核心功能：

| 功能             | 说明                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| **人工标注编辑** | 矩形 / 点 / 多边形三种标注工具，支持对象属性（标签/描述/分组）、复制粘贴、撤销重做、多选 |
| **自动标注**     | 加载 ONNX / TensorRT 模型，对单张图片、全部图片、视频批量推理，自动生成 LabelMe 标注     |
| **格式转换**     | 导出（LabelMe JSON → YOLO TXT，含数据集划分）与导入（YOLO TXT → LabelMe JSON）双向转换   |
| **数据集统计**   | 后台扫描工作目录标注文件，汇总标签种类、实例个数与标注形状分布                           |

支持的任务模式：

| 任务模式            | 自动标注 | 格式转换 |
| ------------------- | -------- | -------- |
| 目标检测（DETECT）  | 支持     | 支持     |
| 姿态估计（POSE）    | 支持     | 支持     |
| 实例分割（SEGMENT） | 支持     | 支持     |
| 文字识别（OCR）     | —        | 预留接口 |

## 2. 系统要求

| 项目     | 要求                                                  |
| -------- | ----------------------------------------------------- |
| 操作系统 | Windows 10 / 11（64 位）                              |
| CPU 版   | 无特殊要求，4 GB 以上内存                             |
| GPU 版   | NVIDIA 显卡 + 已安装显卡驱动（无需安装 CUDA Toolkit） |
| 磁盘空间 | 安装约 1 GB（GPU 版），输出目录预留足够空间           |

**GPU 版说明：**

- GPU 推理基于 TensorRT 引擎，仅需安装 NVIDIA 显卡驱动，无需单独安装 CUDA Toolkit 或 cuDNN。
- GPU 模式下首次使用 ONNX 模型时，程序会弹窗确认将其转换为 TensorRT engine（约需 10~30 分钟，视模型大小而定），转换结果保存在模型同目录下，之后自动复用。
- 若系统未检测到 CUDA 环境，运行设备选择中的 GPU 选项将被自动禁用，仅支持 CPU 模式。

## 3. 安装与启动

### 3.1 安装器安装

1. 双击安装程序（如 `VAI_E_SmartAnnotator_Setup_GPU.exe`）。
2. 按向导提示选择安装目录，完成安装。
3. 从开始菜单或桌面快捷方式启动程序。

### 3.2 开发环境运行（源码）

```bash
conda create -n VAI_E_SmartAnnotator python=3.12.10
conda activate VAI_E_SmartAnnotator
pip install -r requirements.txt
python -m smart_annotator
```

## 4. 界面总览

程序主窗口为 **三栏式标注编辑器**：

| 区域           | 内容                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **菜单栏**     | 文件 / 编辑 / 视图 / 工具 / 统计 / 帮助 六个菜单                                                                               |
| **左侧快捷栏** | 三组按钮：文件操作（打开/保存/删除）、自动标注（加载模型/标注当前图片/标注所有图片/标注视频）、标注工具（编辑/矩形/点/多边形） |
| **中间画布**   | 图像显示与标注绘制/编辑区；与右栏之间的分隔条可拖拽调节宽度                                                                    |
| **右侧信息栏** | 四组列表自上而下：标签列表、对象列表、文件列表、关键点列表；列表高度均可拖拽调节                                               |
| **状态栏**     | 显示当前图片序号（如 `3/120`）、文件名与未保存标记（`（未保存）`）                                                             |

- 画布宽度、右栏宽度与各列表高度均可拖拽调节，并自动持久化（下次启动恢复）。
- 界面配置持久化于 `%APPDATA%/BrilliantAnnotator/render_config.json`。
- 未打开图片时，编辑相关功能自动禁用。

## 6. 人工标注

### 6.1 标注工具

左侧栏/工具菜单提供四种互斥工具（括号内为快捷键）：

| 工具   | 快捷键     | 说明                                         |
| ------ | ---------- | -------------------------------------------- |
| 编辑   | V / Ctrl+E | 编辑模式：选中、拖拽移动、端点缩放、修改属性 |
| 矩形   | R          | 点击两个对角点绘制矩形框                     |
| 点     | P          | 单击放置关键点（点对象进入右侧"关键点"列表） |
| 多边形 | G          | 逐点点击绘制多边形，闭合后完成               |

### 6.2 绘制流程与属性弹窗

绘制完成（矩形第二点点击 / 多边形闭合 / 点放置）后弹出 **"标注对象属性"** 窗口：

- **标签：** 输入框即时过滤下方已有标签列表；单击选择、双击选择并确认，也可直接键入新标签。
- **Group ID：** 可编辑下拉框，下拉项为当前画布已有组号（去重升序），也可键入新值；留空表示不分组。
- **描述：** 底部输入框填写备注（可选）。
- **取消或标签为空：** 该形状不生效（静默丢弃，状态栏提示"未设置标签"）。

### 6.3 编辑操作（编辑菜单 / 画布右键菜单）

| 操作           | 快捷键       | 说明                                     |
| -------------- | ------------ | ---------------------------------------- |
| 撤销           | Ctrl+Z       | 撤销上一步绘制/编辑                      |
| 重做           | Ctrl+Shift+Z | 重做                                     |
| 复制           | Ctrl+C       | 复制画布选中对象到画布内部剪贴板         |
| 粘贴           | Ctrl+V       | 粘贴剪贴板中的对象                       |
| 删除选中标注   | Delete       | 按焦点上下文路由（见 6.4）               |
| 清空标注       | —            | 清空当前图片全部标注                     |
| 删除图片及标注 | Shift+Delete | 删除当前图片文件与其标注文件（含确认框） |

**画布右键菜单**（编辑模式、无绘制草稿时）：对象命中区提供 编辑属性 / 删除 / 复制 / 粘贴；空白处提供 撤销 / 重做；并含 创建矩形 / 创建点 / 创建多边形 / 编辑模式 / 清空标注 切换项，按当前状态自动启用或禁用。

### 6.4 Delete 键的焦点路由

Delete 快捷键按当前焦点控件自动路由：

| 焦点位置       | 行为                                    |
| -------------- | --------------------------------------- |
| 文本输入框     | 不拦截，执行正常文本删除                |
| 对象列表       | 删除列表选中的对象（支持多选批量删除）  |
| 关键点列表     | 删除列表选中的关键点（point 形状）      |
| 文件列表       | 删除选中图片及标注（等同 Shift+Delete） |
| 画布或其他区域 | 删除画布选中形状                        |

## 7. 右侧信息栏

| 列表           | 说明                                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **标签列表**   | 当前工作路径的全部标签（按字母序），每项带类别颜色圆点；单击/双击即设为当前绘制标签                                                               |
| **对象列表**   | 当前图片的非点形状对象，显示 `标签 [G组号]`（有分组时）；支持多选、可见性复选框（取消勾选仅隐藏渲染不删数据）、右键菜单（编辑/删除/进入编辑模式） |
| **文件列表**   | 工作路径全部图片，带只读"已标注"复选框（保存后自动勾选）；单击切换当前图片                                                                        |
| **关键点列表** | 当前图片的点形状对象，交互与对象列表一致；无关键点数据时自动隐藏                                                                                  |

对象列表与画布双向联动：列表选中 ⇔ 画布选中（含多选）；画布选中变化自动同步列表。

**标签来源规则：** 标签列表 = 扫描结果 ∪ 已浏览图片中的标签。浏览图片时标签自动累加（保留原始拼写）；执行"扫描并统计"后由扫描结果统一合并大小写同名标签。

| 菜单项     | 说明                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 扫描并统计 | 对当前工作目录启动后台扫描：弹出非模态进度对话框（可随时中止），完成后弹出 **"标签统计"** 窗口 |

扫描结果同时缓存，供 **导出标注** 对话框自动预填类别列表、关键点列表与任务类型。

## 10. 自动标注

### 10.1 加载模型 / 自动标注设置

入口：**工具 → 加载模型 / 自动标注设置**（或左侧栏"加载模型"）。对话框包含四张卡片：

**运行设备**

- **GPU（推荐）：** 检测到 CUDA 环境时默认选中；未检测到时禁用并回退 CPU。
- **CPU：** ONNX Runtime CPU 推理，兼容无 NVIDIA 显卡的机器。

**模型**

| 设置项   | 说明                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 模型路径 | 选择 `.onnx` 或 `.engine` 模型文件                                                                     |
| 任务类型 | 目标检测 / 姿态估计 / 实例分割。选择模型后自动按模型元数据推导并**锁定**；无法识别时解锁由用户手动选择 |

**检测类别**

- 选择模型后自动解析模型元数据中的类别，以复选框列出（显示 `类别id: 类别名`），默认**全选**。
- 全部勾选等价于不过滤；全部取消勾选（或模型无类别元数据）时检测所有类别。
- 顶部实时显示"已选 X / 共 Y 个类别"，右上角提供 **全选 / 取消全选** 一键切换。

**推理参数**

| 参数         | 默认值 | 说明                                           |
| ------------ | ------ | ---------------------------------------------- |
| BBox 置信度  | 0.25   | 检测框置信度阈值，越高检出越严格               |
| NMS          | 0.7    | 非极大值抑制阈值（重框去重）                   |
| 关键点置信度 | 0.5    | 仅姿态估计任务显示；低于该值的关键点记为 0 0 0 |

点击 **保存设置** 后生效。GPU 模式下选择了 `.onnx` 模型时，程序会弹窗确认是否转换为 TensorRT engine（转换在后台执行，已有同名 `.engine` 时直接复用不重复转换）。

### 10.2 标注当前图片

入口：**工具 → 标注当前图片**。对画布当前图片执行推理，期间弹出**模态进度窗口**（进度条 + 日志 + 可中止），完成后结果自动回填画布（未保存状态），可人工修正后保存。

### 10.3 标注所有图片

入口：**工具 → 标注所有图片**。对工作路径全部图片批量推理，输出与图片同目录的同名 `.json` 标注文件。

若检测到已有标注文件，弹出 **"自动标注选项"**：

- **跳过已标注的图片**（默认）：仅标注尚无标注文件的图片。
- **重新标注并覆盖**：删除原标注文件后全部重新生成（避免无检测结果时残留旧标注）。

### 10.4 标注视频

入口：**工具 → 标注视频**（或左侧栏"标注视频"）。打开独立的 **"标注视频"** 窗口：

| 设置项       | 说明                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 输入路径     | 视频所在目录（默认为主窗口当前工作目录），支持 mp4/avi/mov                   |
| 输出路径     | 抽帧图片与标注输出目录，**默认为 `输入路径/Output`**；手动改过后不再自动跟随 |
| 抽帧间隔(帧) | 每隔多少帧抽取一帧，范围 1~10000，**默认 10**                                |

- **视频列表：** 目录下视频文件动态分批扫描入列（大目录不卡界面），复选框勾选参与标注的视频，默认全选，提供 全选/取消全选 按钮。
- **预览播放器：** 点击视频即可预览；支持 播放/暂停、后退 1s / 快进 1s、变速（0.25x / 0.5x / 1x / 2x / 4x）、进度滑块拖动定位、时间显示。
- **损坏视频保护：** 无法读取帧或连续 5 帧画面停滞时自动终止该视频的标注，防止死循环。
- 点击 **开始标注** 后弹出模态进度窗口（可中止）。

**抽帧输出命名：** `视频名_frame序号.jpg`（序号 6 位补零），如 `video1_frame000010.jpg`；标注 JSON 与抽帧图片同名同目录。

### 10.5 标注收尾

- 图片批量标注完成后自动刷新文件列表的"已标注"状态并重载当前图片。
- 视频标注完成后自动重新扫描工作目录，纳入新增抽帧图片。

## 11. 导出标注（JSON → YOLO）

入口：**工具 → 导出标注**。打开前置检查：必须已打开工作路径，且其中包含图片与 LabelMe JSON 标注（不满足时弹窗拦截，不弹出对话框）。

| 设置项                   | 说明                                                                          |
| ------------------------ | ----------------------------------------------------------------------------- |
| 工作路径                 | 只读显示当前工作路径（源目录固定，源格式锁定 LabelMe）                        |
| 任务类型                 | 目标检测 / 姿态估计 / 实例分割                                                |
| 输出目录                 | 转换结果保存目录                                                              |
| 训练集/验证集/测试集比例 | 默认 0.8 / 0.1 / 0.1（三者之和应为 1.0），仅导出方向显示                      |
| 导出 YOLO 数据集目录结构 | 勾选后按 `images/`、`labels/` 目录结构导出并按比例划分数据集，仅导出方向显示  |
| 可视化标注结果           | 勾选后在输出目录生成标注可视化图片，便于核对                                  |
| 类别列表                 | 拖拽排序，行首数字 = 转换后类别 id（从 0 开始）；支持"一键分析数据集"自动填充 |
| 关键点列表               | 仅姿态估计显示，名称须以 `_point{序号}` 结尾（如 `nose_point0`）              |
| 一键分析数据集           | 自动识别目录层级、标注格式、任务类型（附形状统计）并提取标签填充类别列表      |
| 导入/导出配置            | 将当前设置保存为 JSON 复用（`convert_config.json`）                           |

点击 **开始转换** 后进度条与日志实时显示，**停止** 可随时中断。校验规则：类别列表为空、工作路径无 JSON 标注时弹窗拦截。

**标签格式校验：** 导出时逐文件校验 TXT 行格式（DETECT：`classid x y x y` 5 列；POSE：`5+3×kpt` 列；SEGMENT：`5+2n` 列），非法文件归档到输出目录的 `failed/` 子目录并记录日志，不影响其余文件。

## 12. 导入标注（YOLO → JSON）

入口：**工具 → 导入标注(非json格式->json)**。

| 设置项             | 说明                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| 输入目录           | YOLO TXT 标注与图片所在目录                                                        |
| 输出目录           | LabelMe JSON 输出目录                                                              |
| 文件列表与图像预览 | 仅导入方向显示；点击文件预览图像，支持 ◀ 上一张 / 下一张 ▶ 与 **A / D 快捷键**切换 |

类别列表与关键点列表同样参与反查（TXT 不含标签名，按类别 id 反查类别列表填入 JSON）；"一键分析数据集"可自动推断方向、任务类型并填充类别（TXT 无标签时按类别索引 0,1,2… 自动填充）。

**导入完成后，程序自动将输出目录作为新的工作路径打开**，可直接继续人工标注。

## 14. 常见问题（FAQ）

**Q1：界面提示"未检测到 CUDA，仅支持 CPU"？**

GPU 选项被禁用说明 TensorRT 或 CUDA 相关组件不可用。请确认使用的是 GPU 版安装包，且已安装 NVIDIA 显卡驱动。CPU 版安装包不含 GPU 组件，属正常现象。

**Q2：GPU 模式下选择 ONNX 模型后弹窗提示转换 engine？**

GPU 推理使用 TensorRT engine 模型。首次使用 ONNX 模型时程序会请求确认转换为 engine（约 10~30 分钟），转换结果保存在模型同目录；此后加载自动复用。若取消转换，启动标注时会提示需先完成转换。

**Q3：检测类别列表显示"未提供类别信息"？**

所选模型的元数据中不含类别数据。此时不做类别过滤，将检测模型支持的所有类别。如需按类别过滤，请使用带类别元数据导出的 YOLO 系 ONNX 模型，或重新用工具转换一次模型。

**Q4：选择 `.engine` 模型后类别列表显示"未提供类别信息"？**

程序优先读取 engine 文件内嵌元数据；为空说明该 engine 由旧版本程序转换、未写入元数据，且同目录下无同名 `.onnx` 可回退。重新转换一次模型即可恢复类别选择功能。

**Q5：自动标注结果中部分类别缺失？**

请检查 **检测类别** 卡片中对应类别是否勾选。只有勾选的类别才会写入标注文件。

**Q6：GPU 推理速度没有明显提升？**

请确认运行设备选择了 GPU，且使用的是 engine 模型（进度日志中会显示模型路径）。

**Q7：导出标注时部分文件被归档到 `failed/` 目录？**

这些文件的标注格式未通过校验（如标签列数不符合当前任务类型、类别 id 超出类别列表范围等）。修正后在导出日志中可查看具体原因，重新导出即可。

**Q8：删除了图片/标注还能恢复吗？**

"删除图片及标注"与"重新标注并覆盖"均为**直接删除文件**且无回收站确认恢复机制，请谨慎操作并提前备份重要数据。
